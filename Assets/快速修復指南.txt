⚡ 快速測試步驟
===============================================

1. 運行遊戲（Host + Client）
2. 輪流擊殺對方測試重生
3. 如果看不見對方，按 F1 查看狀態
4. 按 F2 強制修復渲染器
5. 觀察 Console 日誌

===============================================
🎮 快捷鍵
===============================================

F1 - 檢查所有玩家的渲染器狀態
F2 - 強制啟用所有玩家的渲染器

===============================================
✅ 預期的 Console 輸出
===============================================

死亡時：
[Server] 玩家 X 受到 20 點傷害，剩餘血量: 0
[Server] 玩家 X 死亡，準備重生
[Server] HandleDeath: 開始處理玩家 X 的死亡效果
[Server] 禁用碰撞器
[Server] 禁用 5 個渲染器
[Server] 停止物理模擬

重生時：
[Server] 開始重生玩家 X
[Server] 設置玩家 X 位置為: (0.0, 0.0, 0.0)
[Server] RespawnClientRpc: 開始重生玩家 X
[Server] 緩存了 5 個渲染器
[Server] 啟用碰撞器
[Server] 啟用 5 個渲染器
[Server] 恢復物理模擬
[Server] 玩家 X 在位置 (0.0, 0.0, 0.0) 重生完成

===============================================
❌ 如果仍有問題
===============================================

1. 確認 Player Prefab 設置：
   □ NetworkObject 存在
   □ NetworkTransform 存在且啟用
   □ Synchronize Position 已勾選

2. 檢查渲染器：
   □ 所有 SpriteRenderer 在 Inspector 中可見
   □ 沒有被其他腳本禁用

3. 重生點設置：
   □ 場景中有 Tag 為 "Respawn" 的物件
   □ 或者使用 RespawnManager

4. 網絡配置：
   □ NetworkManager 正確設置
   □ Player Prefab 已分配

===============================================
🐛 常見錯誤訊息
===============================================

"緩存了 0 個渲染器"
→ 問題：渲染器沒有被找到
→ 解決：檢查 Player Prefab 結構

"玩家 X: 啟用渲染器 0, 禁用渲染器 5"
→ 問題：所有渲染器都被禁用
→ 解決：按 F2 強制啟用

"沒有找到重生點，使用原點"
→ 問題：沒有設置重生點
→ 解決：創建帶 "Respawn" Tag 的物件
